# Kairos

*Everyone has 24 hours a day. Plan your day before it plans you.*

A smart, personalised and practical solution to school/work stressed and last minute tasks.
**Kairos** is an Ai assisted smart schedule, allowing you to fir your tasks into an organised and optimised day.

---

## Key Features

*   **AI Powered Automatic Scheduling:** Saves you time and will maximise time management.
*   **Powerful AI Models:** Intelligent AI Models with optimised prompts for the most uptime and results.
*   **Completely Open Source:** Zero paywalls and full privacy. All source code is hosted right here on GitHub, and all data can be requested at the press of a button. You can even run your own version of Kairos or make your own customisations (see *Try Kairos*)!

# Prerequisites:

MacOS Tahoe Mac/Maacbook **AND/OR** IOS 26 IPad/Iphone.
XCode installed if you plan on launching locally or to edit.
Firebase App Created (Google Authentication and Email Authentication enabled)
```
googlesignin-ios
firebase-ios-sdk
```
Hackclub AI key


## Try Kairos

### 1. Clone the Repo
```
git clone https://github.com/MRHWCKRR/Kairos-IOS.git
```

Open the cloned repo and open Xcode.

You will need to provide your own key from Hackclub's free AI:
https://ai.hackclub.com

Create an AI key, and make sure to copy it somewhere safe (you will be needing it soon!)

Make sure all dependencies are installed, and make sure the app signage is the same as the one in Firebase (e.g. com.google.app)

You will need to place the HackClub AI key for the AI chatbot to work ($4.00 credit free)

Build the app, and assuming no errors are in my code, it should connect to the virtual (or physical) IPhone/IPad and launch Kairos.

### 2. Get The App

Kairos is available on the web, Android and IOS.

The website has more information:
https://kairos-xi-two.vercel.app

Check out their repos!

https://github.com/MRHWCKRR/Kairos
https://github.com/MRHWCKRR/Kairos-Android
